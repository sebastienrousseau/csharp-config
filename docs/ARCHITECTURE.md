# `@sebastienrousseau/csharp-config` Architecture

Shareable C# / .NET configuration providing standardized Roslyn analyzer, EditorConfig, and OmniSharp rules adhering to modern 2026 standards.

## Design Principles
- Single source of truth for C# fleet configurations.
- Multi-format exports (CommonJS, ESM, TypeScript declarations).
- 100% test coverage with zero runtime production dependencies.
